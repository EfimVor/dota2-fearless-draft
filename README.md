# Dota 2 — Fearless Draft (Мультиплеер)

Интерактивный драфт героев Dota 2 с поддержкой **игры по интернету**.
Один создаёт комнату, второй подключается по ссылке.

---

## 🚀 Быстрый старт: Render (бесплатно, 5 минут)

### 1. Загрузите на GitHub
- Создайте новый репозиторий на [github.com](https://github.com/new)
- Загрузите ВСЕ файлы из этой папки в репозиторий

### 2. Подключите Render
- Зайдите на [render.com](https://render.com) → «New Web Service»
- Подключите GitHub → выберите репозиторий
- Поля заполнятся автоматически:
  - Build Command: `npm install`
  - Start Command: `node server.js`
- Нажмите **Create Web Service**

### 3. Готово!
Через 2–3 минуты Render выдаст ссылку:
`https://dota2-fearless-draft.onrender.com`

Отправьте её сопернику — и играйте!

---

## 🎮 Как играть

1. Оба заходят на сайт
2. Один жмёт **🎯 Создать комнату** → копирует ссылку (📋)
3. Второй переходит по ссылке (или вводит код)
4. Каждый жмёт **«Стать капитаном»** (Radiant / Dire)
5. Жмите **⚔️ Новая серия**
6. Фаза банов (по 3) → Фаза пиков (по 5)
7. Укажите победителя → следующая игра

## ⚙️ Настройки

Через кнопку ⚙️: героев на атрибут, банов, пиков, порядок драфта.

## 🔒 Fearless

Выбранные герои блокируются на ВСЮ серию. Новый пул — каждую игру.

## ⌨️ Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl+Z` | Отменить |
| `Ctrl+N` | Следующая игра |
| `Esc` | Закрыть окна |
